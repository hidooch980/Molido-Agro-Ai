# معماری فنی Molido Agro AI

## اصول
- Android Native، Kotlin و Jetpack Compose
- فارسی و RTL به‌عنوان تجربه پیش‌فرض
- Local-first: ثبت و مشاهده داده‌های اصلی بدون اینترنت
- Hybrid AI: مدل محلی برای وظایف پشتیبانی‌شده و سرویس ابری اختیاری
- ماژولار، قابل آزمون و بدون وابستگی به سرور اختصاصی کاربر

## لایه‌ها
1. Presentation: Compose، وضعیت صفحه و ناوبری
2. Domain: قواعد کشت، محاسبات و موارد استفاده
3. Data: Room، DataStore، مخازن داده و همگام‌سازی
4. AI: قرارداد یکسان برای LocalInference و CloudInference
5. Platform: CameraX، WorkManager و قابلیت‌های Android

## مرزبندی هوش مصنوعی
- LocalInference فقط وقتی فعال است که فایل مدل، برچسب‌ها، مجوز استفاده و آزمون عملکرد موجود باشد.
- CloudInference پشت یک رابط Provider قرار می‌گیرد؛ کلید API در APK ذخیره نمی‌شود.
- پاسخ مدل زبانی به‌تنهایی مجوز توصیه سم یا دوز مصرف نیست.
- نتیجه تشخیص باید شامل نام مدل، نسخه، زمان، سطح اطمینان و هشدار محدودیت باشد.

## ذخیره‌سازی و همگام‌سازی
- Room منبع حقیقت محلی برای عملیات ثبت‌شده است.
- صف همگام‌سازی با شناسه idempotency و سیاست retry طراحی می‌شود.
- تعارض‌ها نباید با آخرین نوشتن کورکورانه حل شوند؛ تاریخچه تغییرات حفظ می‌شود.
- پشتیبان‌گیری باید رمزگذاری‌شده، قابل خروجی و قابل بازیابی باشد.

## حریم خصوصی
- ارسال عکس، موقعیت یا سوابق به ابر باید با اطلاع و رضایت کاربر باشد.
- حداقل‌سازی داده، حذف داده و مدیریت مجوزها الزامی است.
- هیچ secret در کد، مخزن یا بسته APK قرار نمی‌گیرد.

## محدودیت نسخه پایه
نسخه فعلی فقط پایه ساخت اندروید و داشبورد فارسی را ایجاد می‌کند. تشخیص بیماری، همگام‌سازی، مدل محلی، سرویس ابری و مدیریت واقعی هنوز پیاده‌سازی نشده‌اند.
