# ایمنی توصیه‌های کشاورزی

1. تشخیص تصویری یک فرضیه تصمیم‌یار است، نه تشخیص قطعی آزمایشگاهی.
2. در اطمینان پایین یا تصویر نامناسب، سیستم باید از نتیجه قطعی خودداری کند.
3. توصیه سم فقط با داده معتبر ثبت‌شده، برچسب مجاز، محصول هدف، ماده مؤثره و مقررات محل قابل نمایش است.
4. دوز مصرف، اختلاط، دوره کارنس و فاصله ورود مجدد نباید حدس زده شوند.
5. توصیه‌های پرخطر نیازمند تأیید کارشناس واجد صلاحیت هستند.
6. اقدامات زیستی، زراعی و مدیریت تلفیقی آفات (IPM) باید بررسی شوند.
7. زمان و منبع هر توصیه ثبت شود.
8. کاربر باید بتواند توصیه را رد یا به متخصص ارجاع دهد.
9. خروجی هوش مصنوعی مولد نباید به‌عنوان منبع علمی مستقل نمایش داده شود.
